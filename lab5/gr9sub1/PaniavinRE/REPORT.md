## Задания, выполненные в рамках Варианта 1

### Задание A — Hello World модуль с параметром
- Реализован параметр `message` через `module_param`
- При загрузке без параметра выводится приветствие с ФИО
- При загрузке с параметром выводится переданное сообщение
- Корректно работает загрузка/выгрузка

### Задание B — /proc файл со статистикой системы (основное требование Варианта 1)
Создан файл `/proc/student_info`, который при каждом чтении выводит:
- ФИО, группа, подгруппа, вариант
- Время загрузки модуля в jiffies
- Счётчик обращений к файлу
- **Статистику системы:**
  - Количество запущенных процессов (через `for_each_process`)
  - Объём общей, используемой и свободной оперативной памяти (в МБ)
  - Время работы системы (uptime) в секундах

### Задание C — Character device `/dev/mychardev`
- Динамически выделяется major-номер
- Реализованы операции `open`, `release`, `read`, `write`
- Буфер 1024 байта, данные сохраняются между записями
- Поддерживается последовательное чтение с помощью `loff_t *off`
- Корректная очистка ресурсов при выгрузке
