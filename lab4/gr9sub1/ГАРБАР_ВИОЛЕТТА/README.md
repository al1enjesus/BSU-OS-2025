# Лабораторная работа 4: Анализ производительности системы

Набор утилит для анализа производительности ввода-вывода и использования памяти в Linux.

## Программы

### 1. Memory Profiler (`memory_profiler`)
Анализатор использования памяти процессами.

**Компиляция:**
```
make memory_profiler
Примеры использования:
# Базовая информация о процессе
./memory_profiler 1234

# Мониторинг в реальном времени
./memory_profiler 1234 --watch

# Мониторинг с интервалом 5 секунд
./memory_profiler 1234 --watch 5

# Сравнение двух процессов
./memory_profiler 1234 --compare 5678

# Показать карту памяти
./memory_profiler 1234 --map
```
### 2. Disk I/O Workload (disk_io_workload)
Генератор нагрузки на диск для тестирования производительности.

Компиляция:
```
make disk_io_workload

Запуск:
./disk_io_workload
```
###3. I/O Benchmark (io_benchmark)
Сравнение производительности различных методов ввода-вывода.
```
Компиляция:
make io_benchmark
Запуск:
./io_benchmark
```

### 4. Memory Analysis (memory_analysis)
Демонстрация различных методов выделения памяти.
```
Компиляция:
make memory_analysis
Запуск:
./memory_analysis
```

Сборка всех программ: **make all**
Очистка: **make clean**
**Во время работы** программ можно использовать системные утилиты
