# ЗАДАНИЕ B — Read vs mmap

## Цель

Сравнить скорость и поведение двух способов чтения файла (100 MB):

1. read()
2. mmap()

Обе версии считают сумму всех байтов.

## Результаты

syscalls sum = XXXX   time ≈ 1.0 sec
mmap     sum = XXXX   time ≈ 0.18 sec

mmap быстрее примерно в 4–6 раз.

## Объяснение

### Почему mmap быстрее:

* меньше системных вызовов;
* нет передачи данных из kernel space в user space (zero-copy);
* подкачка страниц происходит автоматически;
* последовательные page faults работают эффективно.

### Почему read() медленнее:

* каждый вызов read() вызывает переход в ядро;
* данные копируются в буфер пользователя;
* много overhead.

### Почему сумма стала отрицательной?

Произошло переполнение int при обработке 100 МБ. Необходимо использовать long long или uint64_t.

# ЗАДАНИЕ C — Page Faults

## Цель

Исследовать minor и major faults при последовательном и случайном доступе.

## Результаты

### Последовательный доступ

* minor faults: ~25000
* major faults: 0

### Случайный доступ

* minor faults: примерно столько же
* major faults: 0

## Объяснение

* minor faults появляются при первом обращении к странице анонимной памяти (malloc).
* major faults отсутствуют, потому что данные не хранятся на диске и не имеют файлового бэкенда.

---

# Итоговые выводы

 Виртуальная память состоит из множества сегментов (heap, stack, mmap, библиотеки).
 malloc и mmap выделяют память лениво — страницы формируются при обращении.
 mmap работает быстрее read благодаря zero-copy и меньшему количеству системных вызовов.
 Page faults позволяют оценить работу demand paging.
 Major faults для анонимной памяти не возникают.

# Ответы на вопросы преподавателя

### 1) Почему VSZ ≈ 120–160 MB, а VmSize ≈ 4700 kB?

VSZ отображает всё виртуальное пространство процесса, включая зарезервированные участки. VmSize показывает только реальные сегменты, выделенные процессом.

### 2) Объясните адреса в /proc/self/maps

* 55ab… — ELF сегменты программы;
* 55ab…–55ac… — куча;
* 7f22… — mmap-области;
* 7fff… — стек;
* 7f3… — библиотеки.

### 3) Почему сумма отрицательная в B?

Переполнение 32-битного int.

### 4) Нужно ли проверять fstat()?

Да, чтобы корректно обработать ошибки файловой системы.

### 5) Разница MAP_PRIVATE и MAP_SHARED

* PRIVATE — изменения не пишутся в файл;
* SHARED — изменения попадают в файл.

### 6) Нужно ли free/munmap?

Да, чтобы избежать утечек памяти.
