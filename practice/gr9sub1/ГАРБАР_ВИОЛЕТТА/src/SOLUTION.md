#Ответы на вопросы


##Часть 1: Обнаружение процесса
###1. Как получить список всех запущенных процессов в Linux?
Использовать команду *ps aux*
Читать директорию /proc
Использовать библиотеку psutil в Python

###2. Как отфильтровать процессы по имени (например, найти "telegram")?
Использовать *pgrep process_name*
Использовать *ps aux | grep process_name*

###3. Какая информация нужна о процессе для его завершения?
PID (Process ID)
Имя процесса (для подтверждения)

###4. Как часто нужно проверять список процессов, чтобы не нагружать систему?
Интервал 1-5 секунд оптимален


##Часть 2: Завершение процесса
###5. Какие сигналы можно отправить процессу в Linux для его завершения?
SIGTERM (15) - *graceful shutdown*
SIGKILL (9) - принудительное завершение
SIGINT (2) - прерывание

###6. В чём разница между SIGTERM и SIGKILL?
SIGTERM позволяет процессу корректно завершиться
SIGKILL немедленно убивает процесс без cleanup

###7. Как отправить сигнал процессу из Python?
*os.kill(pid, signal.SIGTERM)*
*subprocess.run(['kill', '-TERM', str(pid)])*

###8. Нужны ли специальные права (root) для завершения чужого процесса?
Да, обычно нужны права root или владельца процесса


##Часть 3: GUI уведомление (опционально)
###9. Как показать message box (всплывающее окно) в Linux?
*zenity --info*
*notify-send* для уведомлений
*tkinter* для кастомных окон

###10. Какие инструменты/библиотеки можно использовать для GUI в Python?
*tkinter* (встроенный в Python)
*PyQt5* (продвинутый GUI)

###11. Как сделать, чтобы окно появлялось поверх всех окон?
Установить атрибут "always-on-top"


##Часть 4: Управление экраном (опционально)
###12. Как программно управлять яркостью экрана в Linux?
*xrandr --output DP-1 --brightness 0.5*
Через */sys/class/backlight/*
###13. Как выключить монитор через командную строку?
*xset dpms force off*


##Часть 5: Архитектура решения
###14. Как организовать бесконечный цикл мониторинга?
*while True: с time.sleep()*
Использовать планировщик

###15. Как обеспечить, чтобы скрипт запускался автоматически при старте системы?
Добавить в crontab с @reboot
Создать *systemd service*

###16. Как сделать скрипт незаметным для пользователя?
Запускать как демон или изменить имя процесса


##Часть 6: Защита и обнаружение
###17. Как обычный пользователь может обнаружить такой "вирус" на своей системе?
*ps aux | grep watchdog*
Проверить crontab
Мониторинг необычной активности

###18. Как защититься от подобного скрипта?
Использовать SELinux/AppArmor
Ограничить права пользователей и мониторить процессы

###19. Какие системные механизмы Linux могут помешать работе такого скрипта?
*Process namespaces*
*User permissions*
