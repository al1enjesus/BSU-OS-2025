## Описание
Учебный «watchdog», который обнаруживает запуск Firefox и сразу завершает процесс, показывая пользователю предупреждающее сообщение через zenity.

## Требования
- Linux (Ubuntu/Debian рекомендованы)
- Python 3.x
- Установленный zenity (для всплывающих окон)
- Доступ к pgrep и kill (обычно в составе procps)

## Запуск
Обычный запуск (видно вывод):
```bash
python3 watchdog.py
```

Запуск в фоне без терминала:
```bash
nohup python3 watchdog.py &
```

Проверить, что скрипт запущен:
```bash
pgrep -af python
```

Остановить:
Найти PID и послать сигнал:
```bash
pgrep -af python
kill <PID>
```
Либо при запуске в терминале: Ctrl+Z (приостанавливает), затем при необходимости kill.

## Проверка работы
1) Запустите Firefox (например, из меню или командой firefox).
2) Watchdog обнаружит процесс и отправит SIGKILL, затем отобразит окно zenity с предупреждением “net net!!”.

## Ожидаемое поведение и пример вывода
Поведение:

Скрипт раз в 0.5 секунды проверяет наличие процесса firefox.
Если находит — отправляет SIGKILL целевому PID.
После убийства — показывает всплывающее окно с сообщением от zenity: “net net!!”.
Цикл продолжается, пока вы не остановите скрипт.
