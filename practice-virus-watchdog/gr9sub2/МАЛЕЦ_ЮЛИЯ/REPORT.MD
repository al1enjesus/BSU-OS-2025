# Отчет о работе Watchdog-скрипта

## Описание проекта

Watchdog-скрипт предназначен для мониторинга и блокировки запуска приложения Telegram. При обнаружении процесса Telegram скрипт:
1. Завершает процесс
2. Показывает предупреждающее сообщение
3. Активирует блокировку экрана

## Реализация

### Bash-версия (`watchdog.sh`)
- Использует `pgrep` для поиска процессов
- Применяет `SIGKILL` для принудительного завершения
- Показывает уведомление через `zenity`
- Активирует блокировку через `xdg-screensaver`

### Python-версия (`watchdog.py`)
- Аналогичная функциональность через `subprocess`
- Базовая обработка ошибок через `try-except`

## Ответы на вопросы

### Почему выбрана задержка именно 0.5 секунды?
Задержка 0.5 секунды обеспечивает баланс между:
- **Отзывчивостью**: Быстрое обнаружение запуска Telegram
- **Производительностью**: Минимальная нагрузка на CPU (2 проверки в секунду)
- **Практичностью**: Достаточно для обнаружения, но не создает избыточную нагрузку

### Что произойдет, если Telegram запущен несколькими процессами?
Текущий код обрабатывает только первый найденный PID. `pgrep` возвращает первый найденный процесс, остальные остаются активными. Это критическая проблема безопасности.

### Как пользователь может остановить watchdog-скрипт?
**Bash-версия**: Graceful shutdown через `SIGINT`/`SIGTERM` (trap настроен)
**Python-версия**: Только принудительное завершение (`SIGKILL`)

### Почему используется SIGKILL вместо SIGTERM?
SIGKILL выбран для гарантированного завершения, но это:
- **Проблематично**: Не позволяет Telegram сохранить данные
- **Агрессивно**: Может повредить пользовательские данные
- **Неэтично**: Нарушает принципы корректного завершения процессов

### Как скрипт поведет себя, если zenity или xdg-screensaver не установлены?
- **zenity отсутствует**: Скрипт завершится с ошибкой
- **xdg-screensaver отсутствует**: Блокировка экрана не сработает
- **Оба отсутствуют**: Частичная функциональность

### Тестирование в разных DE
Скрипт тестировался только в базовой среде. `xdg-screensaver` может работать по-разному в:
- **GNOME**: Полная поддержка
- **KDE**: Может требовать дополнительные настройки
- **XFCE**: Базовая поддержка
