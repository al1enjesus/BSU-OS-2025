Краткий отчет о выполнении Лабораторная 1 — Bash: анализ логов Цель: освоить базовые команды командной строки, работа с файлами логов.
ОС: Ubuntu 24.04.3
Задание А: Частотный анализ слов в syslog (TOP‑5)
Цель: Подсчитать 5 самых частых слов “слов” в /var/log/syslog.
Решение:
Использовался конвейер:
cat /var/log/syslog
| tr -cs '[:alnum:]' '\n'
| tr '[:upper:]' '[:lower:]'
| sort
| uniq -c
| sort -nr
| head -n 5
Пояснение для конвеера:
    cat /var/log/syslog - считывание содержимого лога syslog
    tr -cs '[:alnum:]' '\n' - заменяет все НЕ-буквенно-цифровые символы на переводы строк (разбивает текст на слова)
    tr '[:upper:]' '[:lower:]' - преобразует все буквы в нижний регистр
    sort - сортирует слова в алфавитном порядке
    uniq -c - подсчитывает количество уникальных слов
    sort -nr - сортирует по числу вхождений (по убыванию)
    head -n 5 - выводит первые 5 строк
В итоге получен список из 5 самых часто встречаемых слов, вот какие у меня эти слова:

  37365 11
  36898 2025
  34481 dorime
  15118 keysym

Задание Б: Неудачные попытки входа (auth.log)
Цель: Найти строки с Failed или Invalid в `/var/log/auth.log`, извлечь IP-адреса (имена пользователей), и подсчитать TOP-10 источников. Замаскировать последний октет IP-адресов.
Решение:
Использовалсяс конвеер:
sudo grep -aEi 'Failed|Invalid' /var/log/auth.log \
  | awk '{for (i=1;i<=NF;i++) if ($i ~ /^[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+$/) print $i}' \
  | sed -E 's/([0-9]+\.[0-9]+\.[0-9]+\.)[0-9]+/\1x/g' \
  | sort \
  | uniq -c \
  | sort -nr \
  | head -10
Пояснения для конвеера:
    grep - ищет строки, где есть Failed или Invalid
    awk - из каждой строки берётся только IP‑адрес (если он там есть)
    sed - маскирует последний октет
    sort — сортирует все IP по алфавиту;
    uniq -c — убирает дубли и добавляет слева счётчик, сколько раз каждая строка встретилась
    sort -nr — сортирует по числам (-n) и по убыванию (-r)
    head -10 — взять только TOP‑10

В) Установки пакетов (dpkg.log)
Цель: посчитать, какие пакеты устанавливались чаще всегои и вывести TOP 10
Решение:
Использовался конвеер:
sudo grep ' install ' /var/log/dpkg.log \
  | awk '{print $4}' \
  | sed 's/:.*//' \
  | sort \
  | uniq -c \
  | sort -nr \
  | head -10
Пояснения для конвеера:
    grep'install' - берёт только строки с действием install
    awk '{print $4}' - выводит 4‑е поле, то есть имя_пакета:архитектура
    sed 's/:.*//' - отрезает часть после двоеточия, остаётся только имя пакета 
    sort | uniq - c - сортирует и считает, сколько раз каждый пакет устанавливался
    sort -nr | head -10 — сортирует по убыванию и выводит TOP‑10 самых часто устанавливаемых пакетов
